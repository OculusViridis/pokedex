## ## Descripción

Una aplicación web sencilla que funciona como una Pokédex. Consume datos de la [PokéAPI](https://pokeapi.co/) para mostrar información sobre diferentes Pokémon, permitiendo a los usuarios buscar, ver detalles y guardar una lista de sus favoritos.

## ## 🚀 Características Principales
* [cite_start]**Búsqueda Dinámica**: Busca cualquier Pokémon por su nombre o número de ID[cite: 19].
* **Carga Aleatoria**: Descubre nuevos Pokémon con un botón que carga 20 criaturas al azar.
* [cite_start]**Vista de Detalles Completa**: Muestra la imagen oficial, tipo(s), altura, peso y estadísticas base de cada Pokémon[cite: 23, 24, 25, 26, 27].
* [cite_start]**Sistema de Favoritos**: Guarda tus Pokémon preferidos[cite: 29]. [cite_start]La lista persiste incluso si recargas o cierras la página gracias al uso de `localStorage`[cite: 30].
* [cite_start]**Diseño Responsivo**: La interfaz se adapta perfectamente a dispositivos de escritorio y móviles[cite: 36].
* **Navegación Mejorada**: Incluye un botón para desplazarse suavemente a la sección de favoritos, ideal para la vista móvil.

## ## 💻 Tecnologías Utilizadas
* [cite_start]**HTML5**: Para la estructura y maquetación del contenido[cite: 9].
* [cite_start]**CSS3**: Para los estilos, utilizando la metodología **BEM** y un diseño responsivo con Flexbox y Grid[cite: 9, 36, 37].
* [cite_start]**JavaScript (Puro/Vanilla)**: Para toda la lógica de la aplicación, incluyendo[cite: 9]:
    * [cite_start]**Fetch API**: para el consumo de datos desde la PokéAPI[cite: 33].
    * [cite_start]**Manipulación del DOM**: para renderizar la información dinámicamente[cite: 34].
    * [cite_start]**LocalStorage API**: para la persistencia de los favoritos[cite: 30].
